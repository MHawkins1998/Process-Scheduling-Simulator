# CPU Scheduling Simulator

## Overview
This project simulates CPU scheduling algorithms to analyze how different strategies impact process performance.

## Algorithms Implemented
- First Come First Serve (FCFS)
- Shortest Process Next (SPN)
- Shortest Remaining Time (SRT)
- Round Robin
- Priority Scheduling

- Full implementation and code can be found in the PDF report included in this repository.

## Features
- Calculates:
    - Waiting Time
    - Turnaround Time
    - Response Time
- Compares performance across scheduling methods
